# mcp-apps-demo-night

npm-workspaces monorepo. Node >= 22.22.2 (`nvm use` reads `.nvmrc`).

- `apps/web`: the Next.js demo (Fizzy Business order desk + Sparky chat). Its own `AGENTS.md` carries the Next.js version notes; read them before touching Next code.
- `apps/map-app`: the Fizzy Maps MCP app, built with [mcp-use](https://github.com/mcp-use/mcp-use). One tool (`show-map`) bound to one React view (`views/map-view/view.tsx`). `mcp-env.d.ts` is generated by `mcp-use typecheck`.

`npm run dev` at the root starts both. `npm run test:e2e` runs the Playwright suite in `apps/web` with a mocked agent stream on port 3100.
